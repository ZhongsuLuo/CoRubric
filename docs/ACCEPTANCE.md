## 发现并修复的问题

- 当前上传解析器依赖本机 `experiments/` 虚拟环境及路径：提取当前运行代码到 `backend/ocr/`，统一依赖锁文件与包导入。
- 新安装无 case 目录时静态挂载失败：启动时创建运行目录。
- 案例同名或默认标准变化时请求硬编码 rubric：改为以服务端目录为准。
- 报告页总分上限固定 `/100`：跟随当前评分结果/标准的 base_score。
- 原 E2E 数据仍假设全局标准列表、任意案例目录：改为当前持久化 case catalog 数据结构；仅一个标准时验证选定值，不点击已禁用选择器。
- 集成测试需要手工提供 GLOBAL_QA_CONTRACT_PATH：npm 入口统一调用自动导出契约的脚本。
- 一个单元测试漏 mock 案例标准列表：补齐边界 mock，消除被吞掉的 URL 错误，不改变业务断言。
- 生产缺少独立入口：增加认证、同源 API、静态资源和原业务生命周期转发；屏蔽 debug、任意本地路径工具及内部 JSON 文件下载。
