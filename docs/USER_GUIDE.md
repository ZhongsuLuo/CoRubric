# 操作指南

1. 线上打开 HTTPS 域名，输入部署管理员配置的登录信息。首次部署没有案例。
2. 点击 **Upload folder**，选择包含 PDF 的文件夹，核对案例名与文件数量后上传。最多 200 份 PDF，每份 100 MB、合计 500 MB。案例重名会拒绝覆盖。
3. 默认使用 OCR + 区域图像增强解析器。进度持久化，关闭对话框或刷新页面后仍可查看；失败可点击重试未完成文件。未通过完整性检查的报告不会进入评分列表。
4. 解析完成后点击 **Use this case**。上传案例自带空白评分标准，可创建标准，添加评分项、评分点、扣分规则和分值。
5. 核对标准后点击 **Start auto-grading**，按提示确认当前版本。批次进度保存在后端，刷新不会丢失；评分模型需要有效 API 配置。
6. 在 **Report View** 查看报告、图片、模型分数和证据。教师可给分、修正理由、选择证据，修改会记录来源与版本。
7. 教师之间的评分冲突进入 Conflict；教师对模型的修正可能产生评分标准更新提案。查看差异后确认或拒绝，确认会按受影响评分项重新处理。
8. **Global View** 展示班级汇总及证据。若存在阻塞，按准备状态提示回到对应报告或评分项处理。
9. 页顶 **中 / EN** 切换界面语言；不会翻译报告原文。

模型评分为辅助结果，正式成绩仍由教师审核。线上入口没有实验重置按钮；本地演示环境的历史操作记录见忽略目录 `history/`。
